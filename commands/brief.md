# Living Atlas Briefing

Run the Cartographer Living Atlas Briefing for the current workspace.

```bash
cartographer brief
```

Optional position:

```bash
cartographer brief {{file}} {{line}}
```

Summarize Mini Atlas, YOU ARE HERE, corridors, hubs/bridges, fog-of-war, and the start-here suggestion for the user.
