Privacy

Cartographer is local-first by design.

  • No telemetry, analytics, or phone-home
  • No required API keys or cloud account
  • Atlas data lives in .cartographer/ on your machine
  • Git history is read locally when available
  • This website is a static GitHub Pages site — it does not process your code

If you sponsor via GitHub Sponsors or thanks.dev, those platforms have their own privacy policies; Cartographer itself never sees payment data.
