Languages

v0.2 ships deterministic adapters (no native tree-sitter dependency) for:

  • TypeScript / JavaScript (incl. TSX, route heuristics)
  • Python (Flask/FastAPI, Click)
  • Go (handlers, Cobra)
  • Rust (Axum/Actix, Clap/Tauri)

Adapters extract symbols, imports, calls, and entry points. Cross-file linking and territory inference run in core.
